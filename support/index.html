Using Davoid

How do I save a project I can edit later?

Open File → Export Davoid Project… to save a .dd file. It includes your writing, objects and original attachments. Open it through File → Open Davoid Project…. To update a project you already opened, choose Save Back to Project File or press ⌘S on Mac.

How do I move a note to another device?

Export a .dd project and transfer it using AirDrop, iCloud Drive or another file service. Open it in Davoid on the other device. There is currently no automatic synchronization between devices.

How do I export a PDF?

Choose File → Export PDF, then select the paper area, a free selection or all content. PDFs preserve the visible layout. Use a .dd project when you want to keep editing in Davoid.

How do I change the language?

Open More (…) → Language and choose a language, or choose Follow System. The change applies immediately and is remembered when you reopen Davoid. Your own note text is preserved.

How do I change the pen or text settings?

Select the pen, then tap it again to adjust color, width, opacity and stroke taper. Select the body-text tool again to adjust formatting and text size. A pressure-sensitive pen can vary line width while drawing.

How do I move or resize something?

Use Select to select an object. Drag its interior to move it, an edge to stretch it, or a corner to resize it. Hold Shift while dragging a corner on Mac to keep its proportions.

Why does a linked folder need permission again?

A read-only folder link uses permission stored on the original device. After moving a project, select the folder again on the new device. Choose a full folder copy if you want its contents to travel inside the project.

Why can’t I preview a file?

Preview and playback depend on the file type and codecs available on your device. Files that cannot be displayed are kept as attachments and can still be exported in their original format.

What should I include in a problem report?

Include your device, operating-system version, Davoid version and the steps that led to the problem. If you send a screenshot or sample project, first remove any private information you do not want to share.
